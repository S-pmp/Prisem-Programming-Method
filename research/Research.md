# PMP Research Notes

## Status

この文書はPMP（Prisem Programming Method）の正式仕様ではありません。

本資料はPMPの研究過程で発生した疑問、観察結果、考察記録をまとめた研究ログです。

ここに記載される内容は結論ではなく、今後検証される仮説の出発点として記録されています。

---

# はじめに

PMPは当初、

Parts

↓

Model

↓

Core

および

10 Action

を中心としたソフトウェアアーキテクチャとして設計された。しかし研究を続ける中で、次の疑問が発生した。
なぜ既存システムは複雑化するのか。なぜ権限は増え続けるのか。なぜシステムは継続的にパッチを必要とするのか。
なぜ監視は増え続けるのか。

本資料はそれらの疑問を調査した記録である。

---

# Observation 1: AIとコード

研究の出発点はAIによるコード生成だった。

AIは同じ機能を複数の言語で実装できる。

PHP

Java

Python

JavaScript

など表現方法は異なるが、本質的に実現している内容は近い場合が多い。この観察から、コードそのものより、コードが表現している構造の方が重要ではないか
という考えに至った。

---

# Observation 2: なぜパッチは終わらないのか

既存システムは継続的に更新されている。

セキュリティパッチ

機能追加

不具合修正

依存関係更新

これらは長期間続く。

ここで疑問が発生した。
なぜシステムは継続的な修正を必要とするのか。原因の一つとして、結合の増加が存在する可能性がある。変更箇所が他の機能に影響するため、修正の連鎖が発生する。

---

# Observation 3: Database

Databaseの研究では興味深い特徴が見えた。多くのシステムで、最終的に守りたいものはコードではなく情報だった。

例えば、

顧客情報

認証情報

決済情報

契約情報

設計情報

である。

ここから、価値はコードに存在するのではなく、情報に存在するのではないかという仮説が生まれた。

---

# Observation 4: 認証

認証を調査すると、本人確認そのものが目的ではないことが分かった。
本当に必要なのは、本人であることではなく、何ができるかだった。

つまり、

認証

↓

権限

↓

情報

という流れが存在する。

この観察によりAuthorityへの注目が始まった。

---

# Observation 5: OAuth

OAuthやOpenID Connectを調査した結果、重要なのは情報全体ではなく、必要な意味だけを渡すという考え方であることが見えた。

例えば、

年齢確認

会員確認

本人確認

は、個人情報全体を共有しなくても成立する可能性がある。
ここから、Meaningの分離という考え方が生まれた。

---

# Observation 6: Root権限

Root権限の研究では、

システムの中心問題はRootの存在ではないという考察に至った。

問題は、Rootへ価値が集中することである。

Root取得

↓

全体取得

が成立しやすくなる。

つまり、

権限集中

↓

価値集中

という関係が存在する可能性がある。

---

# Observation 7: 監視

既存システムでは監視は重要な機能とされる。

しかし別の疑問が生まれた。

なぜそこまで監視しなければならないのか。

観察の結果、監視対象は次の要素と関係している可能性があった。

権限

依存関係

結合

例外処理

つまり、監視は原因ではなく結果である可能性がある。

---

# Observation 8: Linux

Linuxを調査すると、

権限

経路

責任

がシステム全体に分散されていることが見えた。

さらに、

CPU

Memory

Disk

Network

という異なる要素であっても、

制御

権限

構造

責任

が繰り返し現れる。

ここから、PMPが異なる階層で繰り返し現れる可能性が考察された。

---

# Observation 9: フラクタル仮説

DB

API

認証

Linux

を検討した結果、

似た構造が繰り返し出現しているように見えた。

例えば、

Database

↓

PMP

API

↓

PMP

OS

↓

PMP

というように、異なるスケールで同じような構造が現れる可能性がある。

これを現在、PMP Fractal Hypothesis　として研究中である。

---

# Current Research Direction

現在は次の問いを中心に研究している。

- なぜ権限は増加するのか
- なぜ監視は増加するのか
- なぜ結合は増加するのか
- なぜ価値は集中するのか
- 意味だけを共有できるのか
- 実行だけを交換可能にできるのか
- PMPはOSやDBにも適用可能なのか
- PMP×PMP構造は成立するのか
